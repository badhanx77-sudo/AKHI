# AKHI - personal female AI voice assistant (Android)

Build: upload this folder to a GitHub repo -> Actions tab -> "Build AKHI APK" -> download artifact `AKHI-apk` (app-debug.apk).

First run: Settings -> paste Gemini API key -> "Save & Test". Then give Microphone / Contacts / Calls / SMS permission.
Optional: Accessibility (screen reading, back/home, auto-tap Send), Display over other apps (wake word "AKHI").
